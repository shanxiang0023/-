## 三、需求背景与业务痛点

* **【业务现状】**：NetShort 作为全球分发的短剧出海产品，已在 Google Play 和 App Store 上线北美、东南亚、拉美、日韩、欧洲、中东等全球数十个国家和地区。客服团队日常通过“NS管理系统 -> 客服系统 -> 商店回复”拉取双端评论做常规客诉回复。
* **【核心痛点】**：
  1. **诱导好评违规隐蔽性极高**：部分 5 星好评用户在评论中明确写出“按要求好评返金币/给5星领看剧奖励”（Incentivized Reviews）。应用商店官方（尤其是 Google Play）对此类行为严打，一旦被抓取判定为违规刷评，面临**直接下架、清空评价乃至封号风险**。
  2. **高危客诉滞后导致下架危机**：海外用户在遇到未授权扣费、欺诈指控或内容争议时，常在评论中声称要向 Google/Apple 官方举报、起诉或报警。若人工未能第一时刻响应，极易被商店审核巡检升级为严重合规事件。
  3. **16 种出海多语言壁垒**：评论涵盖英语、越南语、韩语、西班牙语、葡萄牙语、泰语、印尼语等 16 种语言，俚语与变体众多，仅靠中文或单一英语词无法覆盖；必须依托翻译团队建立覆盖全语种的标准词库。
  4. **跨时区拉取与推送不均**：海外各地区与国内存在较大时差，需支持按当地活跃时段自适应配置触发时间与频次。
* **【优化目标】**：打造“后台策略精细配置 -> 多语区分批定时抓取 -> 16语种词库风控评级 -> 飞书机器人分级预警 -> 客服后台一键闭环”的主动防御系统。

### 5.2 新增后台子页面 ——【预警配置】详细说明

> **【菜单层级】**：NS管理系统 -> 客服系统 -> **【预警配置】**（与【商店回复】同级并列）。

#### 1. 顶部搜索栏与操作按钮
* **搜索项（5 个筛选字段）**：
  1. **风险等级**：下拉选择，选项包含 `全部`、`🔴 P0 极高`、`🟠 P1 高危`、`🟡 P2 中危`、`🟢 P3 低危`。
  2. **语言**：下拉选择，选项包含 `全部语言` 以及 16 种出海语种（英语、越南语、韩语、西班牙语、葡萄牙语、泰语、印尼语、繁体中文、日语、马来语、阿拉伯语、俄语、德语、法语、土耳其语、印地语）。
  3. **状态**：下拉选择，选项包含 `全部状态`、`已启用`、`已停用`。
  4. **推送时间**：文本/区间输入框，支持输入具体时间段（如 `08:00 - 24:00`）模糊检索。
  5. **创建人**：文本输入框，支持按创建人姓名/工号模糊搜索。
* **操作按钮**：
  * **【🔍 搜索】**：点击后按上述 5 个条件组合过滤策略列表。
  * **【🔄 重置】**：清空所有搜索条件，恢复默认列表数据。
* **功能操作区（3 个核心功能按钮）**：
  * **【➕ 新建】**：点击直接在当前页面弹出【新建预警监控策略】弹窗。
  * **【📝 关键词录入】**：点击直接在当前页面弹出【关键词录入与分级】弹窗。
  * **【🏷️ 风险等级录入】**：点击直接在当前页面弹出【风险等级录入】弹窗。

#### 2. 预警监控策略列表字段规范
列表按表格形式展示，字段定义如下：

| 序号 | 字段名称 | 字段类型 | 展示与交互规范 | 示例值 |
| :---: | :--- | :--- | :--- | :--- |
| 1 | **编号** | String | 策略唯一编号，递增展示 | `STRAT-2026-001` |
| 2 | **风险等级** | Badge | 带色块标签，按 P0(红)/P1(橙)/P2(黄)/P3(绿) 区分渲染 | `🔴 P0 极高` |
| 3 | **风险分类** | Text | 匹配的触发关键词分类，**一律翻译展示为中文** | `好评返金币 / 激励评论风险` |
| 4 | **触发时间** | Text | 每天执行监控推送的时间区间 | `每日 08:00 - 24:00` |
| 5 | **触发频次** | Text | 监控推送的周期频次 | `每 1 小时 / 次` |
| 6 | **语言范围** | Tags | 该策略覆盖的语种标签列表 | `[英语] [越南语] [韩语] +3` |
| 7 | **星级范围** | Tags | 该策略覆盖的评价星级 | `[1星] [2星] [3星] [5星]` |
| 8 | **状态** | Switch | **开关切换控件 (Toggle Switch)**，点击即时切换启用/停用状态并给出轻提示 | 开启 (Checked) |
| 9 | **创建人** | Text | 策略创建人姓名 | `运营主管_张三` |
| 10 | **创建时间** | DateTime | 策略创建时间戳 | `2026-08-05 10:30` |
| 11 | **操作** | Action | 操作链接：【编辑】（回显弹窗修改）、【删除】（二次确认后移除） | `编辑` \| `删除` |

### 5.3 核心交互弹窗规范

#### 弹窗 1：【➕ 新建预警监控策略】弹窗
* **宽度**：`600px`，居中浮层。
* **表单字段配置**：
  1. **关联风险等级 \***：下拉选择（`🔴 P0 极高风险`、`🟠 P1 高危风险`、`🟡 P2 中危风险`、`🟢 P3 低危风险`）。
  2. **触发时间 (每天几点推送) \***：文本输入框，支持输入每天监控时间范围（如 `每日 08:00 - 24:00` 或固定时点 `09:00`）。
  3. **触发频次 (推送时间) \***：下拉选择（`每 1 小时 / 次`、`每 2 小时 / 次`、`每 4 小时 / 次`、`每天 1 次`）。
  4. **生效语言 (支持多选) \***：多选复选框组，包含 16 种出海语种（英语 EN、越南语 VI、韩语 KO、西班牙语 ES、葡萄牙语 PT 等）。
  5. **星级范围 (1-5星，可多选) \***：多选复选框组，包含 1星、2星、3星、4星、5星（可组合多选，如勾选 1星+5星 重点监控差评与诱导好评）。
  6. **状态 开关 \***：**Toggle Switch 开关**，默认开启；配说明文案“启用后将按设定的频次与时间进行监控推送”。
* **底部按钮**：【返回】（关闭弹窗）、【确认】（校验必填项后保存策略并刷新列表）。

#### 弹窗 2：【📝 关键词录入与分级】弹窗（翻译团队交付模式）
* **宽度**：`720px`，内部支持滚动。
* **顶部 Tab 页签**：
  * **Tab 1：单个录入 (16种语言)**
  * **Tab 2：批量上传 (Excel / CSV 导入)**

##### Tab 1：单个录入交互
1. **输入关键词 (中文主词) \***：输入主词文本，如 `好评返金币`、`官方举报`、`乱扣费`。
2. **勾选归类的风险等级 \***：单选单选框（`🔴 P0 极高`、`🟠 P1 高危`、`🟡 P2 中危`、`🟢 P3 低危`）。
3. **16 种出海语种映射词条录入网格**：
   * 网格布局呈两列并排，覆盖 16 个标准语区：英语(EN)、越南语(VI)、韩语(KO)、西班牙语(ES)、葡萄牙语(PT)、泰语(TH)、印尼语(ID)、繁体中文(ZH-TW)、日语(JA)、马来语(MS)、阿拉伯语(AR)、俄语(RU)、德语(DE)、法语(FR)、土耳其语(TR)、印地语(HI)。
   * 每个语种单元格展示语言名称与国家语言 Code，输入框支持直接粘贴翻译团队提供的词条，并支持使用逗号分隔多个近义变体词。
4. **底部操作**：【取消】、【确认录入 (16语种)】。

##### Tab 2：批量上传交互（极简两步流程）
1. **第 1 步：获取翻译团队标准模版**：
   * 左侧标题：“第 1 步：获取翻译团队标准模版”。
   * 右侧操作按钮：**【📥 下载 16 语种标准模板 (.xlsx)】**，点击即刻生成标准表头模板供交付翻译团队。
2. **第 2 步：上传填写好的翻译文件 (.xlsx / .csv)**：
   * 标题：“第 2 步：上传填写好的翻译文件 (.xlsx / .csv)”。
   * 大尺寸拖拽上传区域（Upload Dropzone），支持点击选择或直接将翻译文件拖入，支持 `.xlsx`、`.xls`、`.csv`，限制单个文件 ≤ 10MB。
   * 选择文件后，上传区域立即反馈变绿并展示已选择文件名与 16 语种字段校验通过提示。
3. **底部操作**：【取消】、【确认批量导入】。

#### 弹窗 3：【🏷️ 风险等级录入】弹窗
* **宽度**：`480px`。
* **表单内容**：
  * 等级名称输入框：如 `P0 极高风险`、`P1 高危风险`。
* **底部操作**：【取消】、【确认录入】（提交后生效并可用于策略与关键词绑定）。
